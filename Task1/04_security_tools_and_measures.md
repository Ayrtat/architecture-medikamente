# Инструменты, способы и меры обеспечения конфиденциальности

## 1. Защита данных при хранении (Data at Rest)

### Инструменты

| Инструмент | Назначение | Приоритет |
|-----------|-----------|-----------|
| BitLocker / VeraCrypt | Шифрование дисков файлового сервера | Критический |
| EFS (Encrypting File System) | Шифрование папок с медкартами | Критический |
| Transparent Data Encryption (TDE) | Шифрование баз данных 1С | Высокий |
| Azure Key Vault / HashiCorp Vault | Управление ключами шифрования | Высокий |

### Меры
- Шифрование всех файлов с классификацией L3 и выше
- Централизованное управление ключами
- Автоматическая ротация ключей каждые 90 дней
- Резервное копирование зашифрованных данных

## 2. Защита данных при передаче (Data in Transit)

### Инструменты

| Инструмент | Назначение | Приоритет |
|-----------|-----------|-----------|
| TLS 1.3 | Шифрование сетевого трафика | Критический |
| WireGuard / IPSec VPN | Защищенный канал с лабораторией | Критический |
| S/MIME | Шифрование email | Высокий |
| SFTP | Безопасная передача файлов | Высокий |

### Меры
- Запрет передачи медданных по незашифрованным каналам
- VPN для всех внешних подключений
- Сертификаты TLS для всех веб-интерфейсов
- Мониторинг сетевого трафика

## 3. Контроль доступа (Access Control)

### Инструменты

| Инструмент | Назначение | Приоритет |
|-----------|-----------|-----------|
| Active Directory + AGPM | Централизованное управление доступом | Критический |
| Azure AD / Okta | Identity and Access Management с 2FA | Высокий |
| Apache Ranger / OPA | Policy-based доступ (ABAC) | Средний |
| PAM решения (CyberArk, BeyondTrust) | Privileged Access Management для IT | Высокий |

### Меры
- RBAC для всех ролей сотрудников
- ABAC для врачей (доступ только к назначенным пациентам)
- Обязательная 2FA для всех пользователей
- Автоматическая блокировка учеток при увольнении
- Break-the-glass для экстренных случаев с аудитом

### Меры

## Архитектура безопасности (Defense in Depth)

```
Layer 7: Пользователь
  → 2FA, обучение, NDA
  
Layer 6: Приложения
  → Шифрование, маскирование, RBAC/ABAC
  
Layer 5: Данные
  → Encryption at rest, классификация, DLP
  
Layer 4: Хосты
  → Антивирус, EDR, патчи
  
Layer 3: Сеть (internal)
  → Сегментация, IDS/IPS
  
Layer 2: Периметр
  → Firewall, VPN
  
Layer 1: Физическая безопасность
  → Контроль доступа в серверную
```

## Приоритизация внедрения

### Критический приоритет (0-3 месяца)
1. BitLocker для дисков
2. Windows Auditing + SIEM
3. RBAC с ограничением прав IT
4. VPN для лаборатории
5. 2FA для всех

### Высокий приоритет (3-6 месяцев)
6. DLP система
7. Обфускация UUID
8. Миграция в защищенную БД
9. Портал для пациентов (DSAR)

### Средний приоритет (6-12 месяцев)
10. Data catalog и lineage
11. Обезличивание для аналитики
12. ISO 27001 сертификация
