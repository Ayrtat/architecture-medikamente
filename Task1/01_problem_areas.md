# Список проблемных зон системы "Медикаменте"

## Критические проблемы безопасности

### 1. Отсутствие шифрования конфиденциальных данных
- Медицинские карты хранятся в виде сканов, то есть в открытов виде
- Excel-файлы с персональными данными не защищены
- Сканы прочих документов без шифрования на общем диске

### 2. Избыточные права доступа
- IT-отдел имеет полный доступ ко всем медицинским данным
- Врачи могут читать карты всех пациентов, не только своих
- Ресепшен имеет доступ ко всем конфиденциальным данным

### 3. Отсутствие аудита и мониторинга
- Нет логирования доступа к медицинским картам
- Невозможно отследить, кто открывал файлы пациентов
- Отсутствие контроля за копированием данных

### 4. Незащищенные каналы передачи данных
- Email без шифрования содержит медицинские данные
- Канал с внешней лабораторией не определен
- Результаты анализов передаются без защиты

### 5. ФИО в названиях файлов и папок
- Папки пациентов содержат ФИО и дату рождения
- Нарушение принципа обфускации
- Легкая утечка метаданных

### 6. Отсутствие процедур реагирования на инциденты
- Нет процесса уведомления Роскомнадзора при утечке (ФЗ-152 ст. 18.1)
- Отсутствие плана действий при компрометации данных

### 7. Двойная запись данных
- Кассиры вручную дублируют данные в Excel и 1С
- Риск расхождений и ошибок
- Дополнительные точки утечки

### 8. Отсутствие механизмов реализации прав субъектов данных
- Нет процесса для доступа пациента к своим данным
- Невозможность удаления данных по запросу
- Нарушение ФЗ-152 ст. 14

## Несоответствия законодательству

- ФЗ-152 "О персональных данных"
- ФЗ-323 "Об основах охраны здоровья"

## Оценка рисков

| Проблема | Вероятность | Влияние | Приоритет |
|----------|-------------|---------|-----------|
| Утечка медицинских данных | Высокая | Критическое | 1 |
| Несанкционированный доступ | Высокая | Критическое | 1 |
| Изменение медицинских записей | Средняя | Критическое | 1 |
| Утечка через email | Высокая | Высокое | 2 |
| Инсайдерская угроза | Средняя | Высокое | 2 |
| Штрафы от регуляторов | Высокая | Высокое | 2 |

## Рекомендации по приоритетам

### Фаза 1 (0-3 месяца)
1. Внедрить шифрование дисков (BitLocker)
2. Настроить аудит доступа к файлам
3. Ограничить права доступа (RBAC)
4. Защитить канал с лабораторией (VPN/TLS)
5. Запретить передачу медданных по email

### Фаза 2 (3-6 месяцев)
6. Миграция с Excel на защищенную БД
7. Внедрение 2FA
8. Обфускация ФИО (переход на UUID)
9. DLP-система

### Фаза 3 (6-12 месяцев)
10. Реализация прав субъектов данных
11. Обезличивание для аналитики
12. Сертификация по ISO 27001
